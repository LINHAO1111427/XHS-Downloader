# 1688 素材与小红书上品

入口：**商品素材 → 1688 商品 / 小红书上品**。

## 采集素材

直接粘贴 1688 商品链接、分享短链或搜索关键词。搜索结果逐个读取详情，商品详情页中的推荐商品不会混入当前商品。主图、详情图、SKU 规格图和视频分组保存。图片损坏可重新下载，超过单组 200 张的部分会记录缺口。

遇到登录页时点击「登录网页采集」，在网页预览中扫码登录或点击输入框，使用预览下方的输入框和按键完成页面操作。打开目标商品并加载详情后点击「采集当前 1688 商品」。登录会话保存在当前运行数据目录中的 `commerce-profiles`，各工作台用户、各平台分开。

旧记录点击「补齐素材」会从已保存详情页恢复规格图信息。缺失或下载失败会保留错误，重新采集缺少的字段会保留既有素材及其来源时间。

## 上品任务

1. 在 1688 商品卡片点击「小红书上品」。同一工作台用户与源商品重复点击会打开同一个任务。
2. 编辑标题、店铺名称、售价、库存，选择要上传的素材。采购价格和源库存留在源资料中，实际售价与可售库存由任务独立填写。这里复制源标题与用户编辑内容；没有调用文案生成模型。
3. 源商品的规格名称进入 SKU 表格；填写各行售价和库存。单规格商品可移除不需要的规格行。类目和运费模板记录为操作提示，在千帆网页选择真实选项。
4. 点击「打开千帆上品网页」。在预览内登录商家账号、进入商品发布、选择类目。预览可点击、拖动、滚动和输入；收起再打开会保留所在网页。
5. 刷新预览，将标题、售价、库存和各组素材对应到页面控件。清楚且唯一的标签会预选，重名控件需要指定。SKU 先选本次规格，再匹配该行价格与库存；系统核对控件所在行的规格名称。
6. 点击「填写选中字段 / 上传素材」。文本逐项回读；文件选择单独记为 `upload_selected`，等待网页实际上传完成。单文件控件每次只选择一张，已上传的相同分组会阻止重复上传。
7. 页面核对完成后可点击「保存草稿」，或在网页执行平台提交。平台可能要求补充类目属性、品牌资质、尺寸或运费选项，继续在预览内填写。
8. 打开包含该商品编号、完整标题和平台状态的列表行或详情页，填写平台商品编号并点击「核验平台结果」。`审核中` 和 `已上架` 分开登记，后续可再次核验审核结果。只有页面证据匹配才更新状态，截图及哈希一起保存。

任务文件和素材副本保存在 `commerce-listings`。默认 Docker 部署位于 `/data`（本机 `DockerData`）。执行截图通过任务的「执行记录」查看。源素材补齐后，点击「同步补齐后的素材」可恢复任务中缺失的副本并追加素材，编辑过的标题、售价和既有选择继续保留。

## 验证范围

自动化覆盖实际 Chromium 的 DOM 填写、文件选择、SKU 行匹配、草稿提示和平台状态核验；测试中的商家网页及商品数据使用隔离夹具，网络请求在测试内响应。另有完整前端测试覆盖登录工作台、创建任务、下载素材包、执行记录和手机布局。

真实店铺的类目布局及最终提交尚待登录后的商品实测。页面控件通过当前 DOM 读取，不依赖固定按钮坐标或商家私有发布接口。登录/验证码及平台要求的额外字段在交互预览中完成。

升级：`docker compose -f deploy/compose.personal.yml build app`，然后运行 `start-web.ps1 -NoBrowser`。服务将使用持久化目录中的原数据。
