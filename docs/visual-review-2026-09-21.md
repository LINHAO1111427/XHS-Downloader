# 拼豆笔：字幕与低粉样本图片复盘

这轮最需要改的是：**让画面里的商品和用途更明确，让字幕帮助读者看动作。** 现有图文的部分画面更像拼豆材料或桌面布置，混剪则同时出现原片字幕与新增说明。继续增加布景和文案长度，未必解决这两个问题。

## 实际看了哪些图

先检索 `Volume/knowledge.db`，读取《爆款笔记拆解》《如何用AI生成小红书爆款封面图【逆向提示词版】》《AI生图-爆款三板斧》、摆件案例及用户已确认反馈，再读取拼豆账号的商品、对标、历史稿与媒体。

对《8月份小红书低粉爆款-孟哥出品》62个商品案例，按小工具、使用场景、手持展示和摆件视觉的关联性，定向抽取12个账号主页截图。它们包含笔记封面缩略图，**不是12篇笔记的完整图片组**。图片此前没有随Markdown正文入库；本轮通过IMA图片阅读器取回原始图片，保留文件哈希和资源ID。读取日期为2026-09-21，图中数字是资料保存时的快照，未重新抓取平台当前数据。

另看本地爆品监测库9个千粉以下账号的商品页与主页截图，以及同品类的拼豆补充包案例122；后者主页显示约1.9万粉，不归入千粉以下样本。还抽查了当前账号最近3张Live首图、3条视频画面和原视频片段。

能迁移的是**商品识别、一个明确问题、可见动作、局部与整体的关系**。颜值型产品可以把质感作为主角；功能型工具更需要读者看懂用途。样本也支持尝试有序排列、颜色关系、局部手持，但没有足够证据给出“某种颜色/占比必爆”的公式。

同品类案例122的主页封面是分类容器、彩色豆子和色卡的有序排列。这对卖豆材很直接。卖拼豆笔时若照搬成只有豆子和色卡，商品就被替换了；适合借鉴颜色秩序，让笔尖、笔身和已铺区域成为视觉中心。

## 现有图文怎样改

![本轮抽查的现有输出](../output/visual-review-20260921/current_outputs.jpg)

最近3张Live首图主要是豆板、串豆针、花朵成品和桌面；飞梭拼豆笔没有清楚出现。第二张看起来是裸露串豆针，不能代表已建档的长条装豆仓、导轨和前端结构。它们可以作为相关手工内容的补充图，承担飞梭拼豆笔销售首图时，商品承接不足。

建议先测试三种首图，不增加每日5篇Live＋5条混剪的排期数量：

1. **动作近景**：真实飞梭笔尖、手指和一段落豆区域同框。让人先注意到正在发生的事，再看清商品。优先用实拍动作作依据。
2. **局部与整体**：清楚展示商品全貌，再以另一张图解释某个可见部位。不要用另一款笔或串豆针代替，不编造隐藏结构。
3. **具体生活场景**：做到一半的图案、正在使用的笔与一两格豆子；减少抢眼摆件、书本、绿植。生活感服务于使用关系。

组图分别承担首图吸引、细节解释、顾虑回答；不是同一支笔换三种背景。缩到约180像素宽时仍看得到商品和关键线索。这一尺寸是本次编辑检查方法，不是平台推荐阈值。

Live首帧要独立成立，不能等动起来才看懂。镜头微动只表示镜头变化；需要下豆动作时使用有依据的原片，不把静态图的推拉称为商品操作。继续保留同标识JPG＋MOV、可播放预览及本地生图中转。

## 字幕与剪映

已核对开源项目 [pyJianYingDraft](https://github.com/GuanYixuan/pyJianYingDraft)。它支持独立视频轨、文本轨、样式、自动换行和SRT。上游0.3.0文档注明：控件自动导出只支持剪映6及以下，新版控件不同；本机目录存在11.3、11.5版本。

本次已实现的是**生成可编辑剪映草稿包**，含原始素材、分镜时间轴、独立说明字幕、SRT及素材重定位脚本。程序前端有“下载剪映编辑包”按钮。新版剪映的无人值守导出尚未接入；本轮没有把生成JSON或通过ZIP校验称为已完成剪映11原生导出。

本地渲染同时优化：短句分页、每屏最多两行、字号按画幅调整；每日工厂从原来的30调整到42基准字号；每镜头可选择上/中/下位置，底部预留20%高度。位置由画面规划选择，画面检查继续核对原片字幕、笔尖和手部；不是已经完成自动OCR避让。

![同一原片、同一说明文字的字幕对照](../output/visual-review-20260921/subtitle-comparison.jpg)

对照样片保持文字与原片相同，只改字号和位置。右侧把说明上移，原片字与新增字不再挤在底部。原片已压制文字仍然存在，剪映导入不会自动把它变成可编辑文字。说明字幕也不冒充逐字语音字幕；样片用于排版检查，未计为新增发布成品。

## 已落地与后续验证

创作流程新增商品分析案例检索；图文参考按相关性、历史使用及文件哈希选取，并保存实际参考ID。视觉计划保存首图吸引点、商品可辨认方式、标题与画面关系、一个主要测试变量，以及每张图新增的信息。成图检查增加缩略图、商品缺席、同类工具替换和图片信息重复检查。普通图片入口也使用更新后的公共摄影规则。

本次用户反馈与图片观察已分别写入本地知识库，观察标注为待验证假设；用实际商品查询核对了每日工厂的9条检索结果，能读到新记录。入库回执见 [learning-receipt.json](../output/visual-review-20260921/learning-receipt.json)。

运行中的程序已重启加载更新。已在实际拼豆账号核对前端68条内容、飞梭拼豆笔关联、完整正文与复制结果，并从既有视频条目下载剪映编辑包；ZIP中的原片分镜轨和独立文本轨通过检查。既有内容状态与正文保持原样，排期仍为每日5篇Live＋5条混剪。实际账号核对见 [runtime-result.json](../output/visual-review-20260921/runtime-result.json)。这项检查不代表剪映11原生打开与导出通过。

这些是创作与编辑方法，效果要由发布数据验证。首轮主要比较动作近景、整体结构、生活场景三种方向；尽量保持标题、正文和发布条件可比。记录第1、3、7天的曝光、阅读、商品点击及可归因订单，按相近发布龄比较。曝光未知时不计算封面点击率；点赞、主观评分与成交分别保留。

可复用制作指令：

```text
先检索当前商品的本地知识、已确认反馈、同类完整样本与最近发布快照。
读取商品原图和实际参考图片，分别记录看见了什么、哪些只是待验证假设。
比较动作近景、局部与整体、生活场景三种首图，选能兑现标题且商品可辨认的一种。
每张图增加一个具体信息；在180像素缩略图中检查首图，不以道具代替在售商品。
字幕只说明画面事实，分短句，并按原片文字、笔尖和手的位置选择留白区。
保存来源ID、视觉计划、测试变量与检查结果；Live完成配对校验后再作为成品。
```

这轮未训练或微调模型，持续学习通过知识检索、图片观察记录、提示词及后续反馈迭代实现。
