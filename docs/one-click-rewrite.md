# 一键图文改写

在「下载」页粘贴一篇小红书笔记的分享文本，选择图片方向和数量，点击「一键改写图文」。低粉爆款列表的星光按钮也可以直接发起改写。

- 自然随拍：窗光、生活环境、克制道具。
- 细节特写：局部与全貌变化，突出图片可确认的细节。
- 场景重构：改变机位、背景和物件关系，保持主体外观。

页面默认一次生成 10 篇独立文案，每篇 6 张配图；也可以选择 1 或 3 篇，以及每篇 1、3 或 6 张图。整批只采集一次对标产品图，十篇共享同一组主体原图并按不同切口依次创作。后续再次提交同一链接时，会优先复用此前已经采集的原图。产品资料、目标读者和篇数选择会在当前浏览器按账号记住。产品外观以本次参考图为准；换成另一种产品时应另选对应的产品素材。

结果按篇显示为独立条目，默认收起，只显示封面缩略图、新文章标题、产品/场景和生成进度。点击条目查看该篇文案、配图、下载操作与设计依据，再次点击收起。可以按标题、产品、场景或正文搜索。自动刷新保持已展开的条目和当前页面的手动编辑；浏览器整页刷新重新加载生成时文案，手工修改请先下载保存。

2026-09-16 十篇专题位于 `output/rewrite-collection/`，包括猫猫 3 篇、狗狗 3 篇、卡皮巴拉 2 篇、折叠镜 2 篇。每篇有独立文案和六张分镜，图片采用项目已配置的生成服务，单独保存到 `articles/01` 至 `articles/10`。`collection-status.json` 记录实际完成数量；制作脚本重跑时只补缺图。真实生成与浏览器样本测试分别保存。

本轮十篇优化版位于 `output/rewrite-refined/`：重写十篇标题及正文，按爆款正文逐篇记录借鉴结构；六图序列由 42 张采集原图裁切整理与 18 张已有 AI 场景组成，未新增图片模型调用。每篇保留原图全貌或结构对照，图片来源独立标记。`index.html` 可离线预览，`十篇优化图文.zip` 包含十篇成品和来源说明，新版任务独立出现在一键图文列表，旧版仍保留。原图没有修改。

任务依次采集正文与图片、读取已有爆款采集库、检索案例和知识、分析参考画面、生成文案与逐张配图。每篇会读取最多 3 篇有完整正文的匹配爆款笔记，只迁移标题钩子、段落功能、心理推进和收尾结构，不把别人的个人经历、产品事实或数据写成当前产品事实。十篇分别使用首屏反差、日常场景、细节观察、空间搭配、选择建议、礼物视角、陪伴氛围、近看质感、顾虑回应和系列总结等不同切口，并参考前面已完成文章，减少标题、开头、场景和收尾重复。

每次最多保存 12 张对标原图，文案规划读取前 6 张主体图和最多 3 张匹配案例图。计划会从主体图形成不可变产品锚点；每张生成图都重复约束产品形状、五官、配色、结构、纹理、印花、缝线与零件位置，并要求真实支撑面、接触阴影、环境反光和手机成像质感。图片生成只使用对应的本次主体图，不把爆款封面或历史案例产品混进去。

结果可复制、编辑、下载当前文案或打包生成图文。打包包含生成时的文案；文本框手工修改可以通过「下载当前文案」保存。任务与已生成素材会保留，刷新页面继续查看；服务重启后的未完成任务显示「可继续」，由用户点击重试。重试保留已成功的阶段，只补缺失图片。任务记录位于知识库数据库同目录的 `rewrite-jobs`，素材保存在下载目录的「一键改写素材」和「AI生成」。

文案规划按现有文案费率计费，每张图片按现有图片费率计费；普通失败会退回该次生成的点数，已成功的内容保留。管理员沿用现有不限量规则。配图没有实际互动测试数据，界面会显示实际读取的案例和知识，供选择方向。

## IMA 知识

在顶部「本地知识库」选择知识类型，再点「导入 IMA / 知识文档」。支持导出或整理后的 UTF-8 TXT、Markdown 和 JSON，单份最大 1 MB；自动分段、保留来源文件名、跳过内容重复片段，导入后在下一次创作时检索。导入面向团队知识库，仅管理员可操作。

JSON 接受以下结构（这属于本程序导入格式，不代表 IMA 官方导出协议）：

```json
{"entries": [{"title": "杯子文案的观察角度", "content": "开头交代桌面场景，用杯把、杯口等可见细节支撑表达，避免硬广。"}]}
```

适合导入的内容包括你的优秀笔记、好坏文案对照、目标人群、真实产品资料、图片拆解和发布后复盘。策略、案例中的经历和数据不会默认当作本次产品事实；本次确认的产品资料仍应在输入框补充。

在线读取已加入：点击顶部云朵按钮「连接 IMA 知识库」，从 `https://ima.qq.com/agent-interface` 获取 Client ID 和 API Key，保存在本项目，读取并选择知识库后启用自动检索。每个项目账号分别保存连接；开启后，普通文案生成与一键图文都会先检索 IMA。可先用「试查」验证实际返回的内容。完整说明见 `docs/ima-integration.md`。

## 验证与恢复

`tests/test_rewrite_workflow.py` 验证后台执行、原图及案例图引用、计划校验、失败退款、补图重试、账号隔离、重启恢复、知识导入和画幅。`tests/check_rewrite_browser.py` 用隔离数据库和模型/CDN样本验证桌面与手机操作、图文 ZIP、刷新恢复和知识导入。样本图片是单色占位图，测试不代表真实模型的视觉质量。

本次改动的差异、修改文件包、原始文件哈希、测试记录及恢复脚本位于 `output/one-click-rewrite/`。恢复脚本只恢复本次代码改动，保留生成素材与知识数据；恢复后重启 Web 服务。
